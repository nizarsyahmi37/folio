# Keyboard shortcuts

The Folio **reader** is fully keyboard operable (ATAG Part A / WCAG 2.1.2).

## Global

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Move focus to the next control or link |
| <kbd>Shift</kbd> + <kbd>Tab</kbd> | Move focus to the previous control or link |
| <kbd>Enter</kbd> | Activate the focused link or button |

The **Skip to main content** link appears on the first Tab.

## Documentation

- Tab through the sidebar to open sections and follow links.
- In-page table of contents links jump to headings.

## Theme

1. Tab to **Choose color theme**
2. <kbd>Enter</kbd> or <kbd>Space</kbd> to open the menu
3. Choose Light, Dark, or System
4. <kbd>Escape</kbd> closes the menu

Browsers may provide additional shortcuts; Folio does not block platform accessibility APIs (UAAG-aligned).
