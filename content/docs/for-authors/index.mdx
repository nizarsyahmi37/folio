# Author guide

Folio helps you ship documentation that meets **WCAG 2.1 AAA** in the reading UI and supports **ATAG 2.0** authoring practices.

## Before you publish

```bash
npm run verify:compliance
```

Fix every **Repair** line, then complete the manual checklist in `docs/atag-manual-checklist.md` in the repository.

## Topics

- [Accessible writing](/docs/for-authors/accessibility) — MDX, images, headings, links
- [Keyboard shortcuts](/docs/for-authors/keyboard-shortcuts) — reader UI (ATAG Part A)
