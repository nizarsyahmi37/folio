# Introduction

Folio turns MDX files in `content/docs/` into a fast, readable site. Edit content in your editor; URLs follow your folder structure.

<Callout type="tip" title="Next step">
  See [Getting started](/docs/getting-started) to add a page and shape the sidebar.
</Callout>

## What you get

- **Sidebar navigation** from `meta.json` in each folder
- **Table of contents** from headings on each page
- **Previous / next** links between pages
- **Light and dark** themes
